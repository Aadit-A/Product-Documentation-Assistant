# TechNova X1 Product Manual v1.0

## Product Overview

The TechNova X1 is a compact network gateway designed for home and small-office connectivity. It provides wired Ethernet networking, dual-band wireless networking, and a web-based administration interface.

## Main Specifications

- Maximum supported storage: 2 TB when an approved external storage device is attached.
- Wireless: dual-band 2.4 GHz and 5 GHz.
- Security: WPA2-Personal and WPA3-Personal.
- Ethernet: one WAN port and four LAN ports.
- Power: 12 V DC adapter.

## Factory Reset

To restore the TechNova X1 to factory defaults, keep the device powered on and press and hold the Reset button for 10 seconds. Release the button when the status indicator begins flashing. A factory reset removes custom network settings and administrator configuration.

## Troubleshooting

### Error E104

Error E104 indicates that the gateway cannot establish a valid upstream network connection. Check the cable connected to the WAN port, restart the upstream modem, and verify the WAN configuration in the administration interface.

### Red Internet Indicator

A red Internet indicator means that the gateway is not detecting a valid upstream Internet connection. Check the WAN cable and the upstream modem before changing wireless settings.

## Unsupported Information

The documentation does not specify support for Wi-Fi 7 or Bluetooth. Do not assume that these features are supported.
